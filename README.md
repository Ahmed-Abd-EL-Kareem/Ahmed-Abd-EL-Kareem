## About Me

Hi, I'm **Ahmed Ayman Abdelkareem**, a Full-Stack Developer from Egypt who enjoys turning ideas into useful web, mobile, and AI-powered applications.

I work across the JavaScript/TypeScript ecosystem, building responsive frontends, backend APIs, and mobile experiences. I'm also exploring practical Generative AI patterns such as LLM integrations, structured outputs, retrieval-augmented generation (RAG), and AI workflow automation.
